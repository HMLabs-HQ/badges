# @henrymmey/badges

## About

This is @henrymmey/badges! It contains cool badges for you to use in your projects.

## Using in your project

Want to add these badges to your page? Head over to the [badge reference](https://henrymmey.github.io/badges-docs/badges/) to find the badges most fitting for your use, and how to use them. You can then copy the HTML code, which I recommend for best customizability, or the Markdown code for your chosen badge, and paste that into your file.

## Adding more badges

Want to add your own badge ideas to the project? Feel free to open up an issue and I'll make one!

You can make badges for your own personal use aswell if I am not available; it's pretty easy to make the badges as long as you know a bit of Figma.
